# 创高体育理论考试题库 · 离线检索

一个**单文件、零依赖、可离线**的题库检索页。打开就能按关键词查题、看标准答案。

- **6810 题 / 31 个科目**
- 判断 3540 · 单选 2792 · 多选 429 · 填空 39 · 问答 10
- 关键词实时检索（支持空格分多个词，AND 关系）· 科目筛选 · 题型筛选 · 命中高亮
- 深色/浅色无关，纯静态，无后端、无追踪、不联网

## 用法

### 一、本机直接查

双击 `index.html`。数据内嵌在页面里，断网也能用。

### 二、部署成在线站点（GitHub Pages）

```bash
git remote add origin git@github.com:<你的账号>/cgtk-quizbank.git
git push -u origin main
```

然后仓库 **Settings → Pages → Source 选 `Deploy from a branch` → Branch 选 `main` / `root` → Save**。

一两分钟后访问 `https://<你的账号>.github.io/cgtk-quizbank/`，手机浏览器也能直接查。

## 目录

```
index.html          完整检索页（题库数据内嵌，1.5 MB）
data/bank.json      题库源数据（6810 条，字段见下）
```

`data/bank.json` 每条记录：

| 字段 | 含义 |
|---|---|
| `i` | 序号 |
| `q` | 题干 |
| `o` | 选项，`[[选项字母, 选项文字], ...]`，判断题为空数组 |
| `a` | 标准答案（判断题：`正确` / `错误`；选择题：字母组合） |
| `t` | 题型 |
| `s` | 所属科目（数组） |
| `src` | 数据来源标记 |
| `qid` | 原站题号（可空） |

改完 `bank.json` 后需要重新把数据内嵌进 `index.html`，或者直接只改 `bank.json` 并把页面改成 `fetch('data/bank.json')` 加载（部署在 Pages 上可用，本机 `file://` 打开会被 CORS 拦）。

## 数据说明

题库整理自创高体育理论考试的公开答题记录，按题干归一化去重、多份记录投票取众数得到标准答案，再与线上题库逐个比对校正。

- 答案以题库记录为准，仅供**平时复习**参考
- 正式考试请以任课教师划定范围为准
- 题目与答案版权归原出题方所有，本项目仅做复习用途的整理

## 更新题库

题库源头站点按学期开关（理论测试期间开放、学期结束关闭）。重开时可以增量补齐：

1. 用采集脚本按题号抓新增/缺失的题
2. 合并去重后覆盖 `data/bank.json`
3. 重新生成 `index.html`
